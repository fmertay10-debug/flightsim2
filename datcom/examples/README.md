# Example cases

Five ready-made DATCOM cases covering the toolchain's vehicle classes.
Regenerate any time with `py examples/make_examples.py` (runs the bundled
DATCOM.exe; a few seconds total).

| Case | Vehicle | Control |
|------|---------|---------|
| `01_rocket_baseline` | 4-fin rocket, ogive nose (27 ft × 16 in) | none |
| `02_rocket_fin_control` | same rocket | δ = −20…+20°: pitch (SYMFLP) + differential roll (ASYFLP) |
| `03_rocket_boattail` | rocket with a 2 ft boattail (base ⌀ 0.8 ft) | none |
| `04_rocket_three_fin` | 3-fin variant (120° spacing, one fin vertical) | none |
| `05_canard_missile` | fixed canard on the forebody + tail fins | δ on the tail: pitch only (roll skipped by design for canard vehicles — see docs/ROADMAP.md, I6) |

## Files per case

| File | What it is |
|------|-----------|
| `for005.dat` | DATCOM input deck (generated by `pydatcom.write_input_file`) |
| `for006.dat` | DATCOM output (static + dynamic + control tables) |
| `aero.npz` | Parsed `AeroData`: all coefficient tables plus `fill_<name>` quality masks |
| `<case>.html` | **Interactive 3-D viewer — double-click, opens in any browser.** Drag to rotate, wheel to zoom, right-drag to pan, double-click to reset |
| `<case>.obj` | The same model as Wavefront .obj, for CAD/3-D tools |

## 3-D visualization (native — no external tools)

The models are generated straight from the `Vehicle` geometry by
`pydatcom.geometry` (true tangent-ogive noses, cruciform fins, boattail,
canard — the same parameters the DATCOM deck uses). The `.html` viewer is
fully self-contained: mesh + renderer in one file, no libraries, no
internet, no installed apps — a browser is all it needs.

From Python, for any vehicle you build:

```python
from pydatcom import Vehicle, vehicle_to_html, vehicle_to_obj, plot_vehicle
v = Vehicle(canard_x=5.0, canard_root=1.2, canard_tip=0.6, canard_height=0.8)
vehicle_to_html(v, "my_missile.html")   # -> double-click to view in browser
vehicle_to_obj(v, "my_missile.obj")     # -> for CAD / 3-D tools
```

Or with matplotlib (`py tools/view_vehicle.py all`).

Load a result without re-running DATCOM:

```python
import numpy as np
z = np.load("examples/02_rocket_fin_control/aero.npz")
cn = z["cn"]            # [nalpha x nmach], alpha mirrored to +-180 deg
ok = ~z["fill_cn"]      # True where the value came directly from DATCOM
```

Or re-parse the committed output:

```python
from pydatcom import import_datcom
aero = import_datcom("examples/02_rocket_fin_control/for006.dat")
```

Coefficient plots (CN/CD/CM vs alpha, derivatives vs Mach, control
effectiveness — needs matplotlib):

```python
from pydatcom.plotting import plot_aero
import matplotlib.pyplot as plt
plot_aero(aero); plt.show()
```
